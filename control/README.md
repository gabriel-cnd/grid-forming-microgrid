# Commande

Implementation des fonctions de commande grid-forming.

- `inner_loops/` : boucles internes de courant et de tension.
- `droop/` : lois de droop puissance-frequence et reactif-tension.
- `virtual_impedance/` : impedance virtuelle.
- `state_machine/` : modes de fonctionnement et transitions.
- `synchronization/` : synchronisation et reconnexion au reseau.
