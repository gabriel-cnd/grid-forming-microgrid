# Modeles

Modeles de puissance et modeles systeme, principalement sous PLECS.

- `components/` : composants reutilisables.
- `single_unit/` : modele d'une unite grid-forming.
- `multi_unit/` : modeles de plusieurs unites et partage de charge.
- `validation/` : modeles ou cas servant a verifier les hypotheses.
