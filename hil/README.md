# Validation HIL

Integration et validation temps reel sur Plexim RT Box.

- `rt_box/` : configuration et artefacts propres a la cible RT Box.
- `interfaces/` : interfaces entre le controleur, le modele et le banc.
- `experiments/` : definitions et automatisation des campagnes d'essais.
- `safety/` : limites, interverrouillages et procedures de securite.
