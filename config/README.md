# Configuration

Configuration versionnee des etudes reproductibles.

- `parameters/` : jeux de parametres physiques et de commande.
- `scenarios/` : scenarios de simulation nommes (`S01_...`, `S02_...`).
- `hil/` : configuration propre aux essais temps reel.

Les secrets, chemins locaux et reglages propres a une machine ne doivent pas etre
ajoutes ici.
